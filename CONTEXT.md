# Скидочные карты

Контекст хранения и использования локальных скидочных карт в мобильном приложении.

## Language

**Скидочная карточка**:
Локальная пользовательская запись с каталожным или произвольным брендом, кодом, опциональным цветом, избранностью, числом открытий и фотографиями карточки.
_Avoid_: карта, карта лояльности

**Каталожный бренд**:
Неизменяемая предзаполненная запись библиотеки брендов со стабильным идентификатором, каноническим названием, алиасами, логотипом бренда и цветом.
_Avoid_: встроенный бренд, известный бренд

**Алиас каталожного бренда**:
Дополнительное имя каталожного бренда, по которому название торговой точки сопоставляется с каноническим.
_Avoid_: regex бренда, синоним

**Скрытый каталожный бренд**:
Каталожный бренд, доступный существующим скидочным карточкам, но исключённый из выбора для новых карточек.
_Avoid_: удалённый бренд, устаревший бренд

**Произвольный бренд**:
Название бренда, заданное внутри скидочной карточки и не являющееся записью каталога. Совпадение названия с каталожным брендом не создаёт связь без явного выбора пользователя.
_Avoid_: пользовательский бренд, новый бренд

**Код карточки**:
Непустая строка, предъявляемая продавцу и отнесённая к типу кода. Одинаковый код может принадлежать нескольким скидочным карточкам.
_Avoid_: номер карты, штрихкод

**Тип кода**:
Формат кода карточки из набора EAN-13, EAN-8, UPC-A, UPC-E, Code 128, Code 39, Code 93, ITF, Codabar, QR, Data Matrix, PDF417, Aztec и «Только текст». Последний предъявляет значение без визуального кода.
_Avoid_: формат штрихкода, тип штрихкода

**Логотип бренда**:
Визуальный знак каталожного бренда, поставляемый вместе с каталогом и не хранящийся в скидочной карточке.
_Avoid_: логотип карточки, пользовательский логотип

**Фотография карточки**:
Локальное изображение физической скидочной карточки, принадлежащее одной карточке.
_Avoid_: логотип, вложение, картинка

**Магазин бренда**:
Подтверждённая торговая точка каталожного бренда в круге 5 км от текущей позиции; среди подходящих выбирается ближайшая.
_Avoid_: POI, локация, координаты карточки, магазин как название скидочной карточки

**Снимок магазинов каталога**:
Поставляемый вместе с приложением набор точек каталожных брендов, из которого выбирается магазин бренда.
_Avoid_: геокэш, координаты скидочной карточки, Places

**Маршрут**:
Пеший или автомобильный путь от текущей позиции до магазина бренда с оценкой времени провайдера.
_Avoid_: навигация, прямая линия
