# Мобильное приложение "Скидочные карты"

Приложение для хранения данных скидочных карт.

## Технологический стек

- Фреймворк: React Native
- Язык: Typescript
- Навигация: react navigation
- Локализация: i18next
- UI Kit: react-native-paper
- Тесты: Jest

## Библиотека брендов

Заранее заполненая разработчиком библиотека брендов

Поля бренда:

- Название бренда
- логотип бренда
- цвет бренда

## Скидочная карточка

Скидочные карточки добавляются и редактируются пользователем

Поля карточки:

- Название карточки / бренд
- тип кода карточки
- код карточки
- цвет карточки
- фотографии карточки
- логотип бренда (из библиотеки брендов или отсутствует)
- цвет карточки (если не задан, то из библиотеки брендов или серый)
- избранная карточка

## Экраны

### Главный экран

Список скидочных карточек. Вверху списка избранные карточки, затем идут карточки отсортированные по расстоянию до ближайшего магазина бренда. Если рядом бренда нет, или при возникновении ошибок с геопозицией, сортируем карточки по частоте их открытия пользователем.

Приложение следит за текущим местоположением пользователя и ищет ближайшие магазины брендов карточек в радиусе 5 км

При клике по элементу списка, пользователь переходит на экран скидочной карточки

### Экран скидочной карточки

кнопка назад ведет к списку карточек

Название бренда карточки, штрихкод/qr-код скидочной карточки. Кнопки удаления и редактирования карточки

если рядом есть магазин бренда, то рисуем OSM карту и рисуем два маршрута до ближайшего магазина: пеший и на автомобиле

под картой написано время пешего и автомобильного маршрута

### Экран добавления новой скилочной карточки

кнопка назад ведет к списку карточек

сканер штрихкодов/qr-кодов

поля для ввода информации о карточке

кнопка сохранения карточки, после сохранения переводим пользователя на главный экран

### Экран редактирования скидочной карточки

кнопка назад ведет к списку карточек

поля для ввода информации о карточке

кнопка сохранения карточки, после сохранения переводим пользователя на главный экран
