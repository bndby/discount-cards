# Собственный ZIP для резервной копии

PWA отдаёт JSON без фотографий карточки; мобильный MVP обязан переносить до двух фото вместе с карточками и не принимает бэкапы PWA. Резервная копия — один ZIP v1 (`manifest.json` + файлы медиа) с импортом «заменить всё»: бинарные фото не раздувают JSON, формат не привязан к схеме SQLite и может эволюционировать отдельным `formatVersion`.

Решение: [Определить мобильную модель скидочной карточки и контракт резервной копии](https://github.com/bndby/discount-cards/issues/15).

## Considered Options

- **JSON как у PWA** — отвергнут: нет места для фото, обещанной совместимости нет.
- **JSON с data-URL / base64** — отвергнут: раздувает снимок и смешивает метаданные с байтами.
- **Бинарный файл SQLite** — отвергнут: не переносит медиа и жёстко связывает бэкап с реализацией хранения.
